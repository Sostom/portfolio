📍 EMPLACEMENT: C:\xampp\htdocs\portfolio\

✅ ÉTAPE 1: BASE DE DONNÉES
─────────────────────────────
1. Démarrer XAMPP Control Panel
2. Lancer Apache et MySQL
3. Ouvrir un terminal et exécuter:
   
   cd C:\xampp\htdocs\portfolio
   C:\xampp\mysql\bin\mysql -u root < data/schema.sql

   ✓ Cela crée la base "portfolio_db" avec:
     - Table users (admin)
     - Table projects (2 projets de démo)

✅ ÉTAPE 2: ACCÉDER AU SITE
─────────────────────────────
📌 Page publique (recruteurs):
   → http://localhost/portfolio/

📌 Espace admin:
   → http://localhost/portfolio/admin/login.php
   
   Identifiants:
   Username: admin
   Password: admin2025!

✅ ÉTAPE 3: UPLOADER VOS PROJETS
─────────────────────────────────
1. Se connecter en admin
2. Cliquer "Nouveau projet"
3. Remplir:
   - Titre (ex: "Bande annonce événementiel 2025")
   - Description
   - Catégorie (montage, cadrage, motion, reportage, autre)
   
4. Choisir le type de média:
   ☐ Upload fichier MP4/WebM (max 50 Mo)
   ☐ Lien YouTube (coller l'URL complète)
   ☐ Lien Vimeo (coller l'URL complète)

5. (Optionnel) Ajouter une miniature (thumbnail)
6. Cocher "Mettre en vedette" pour les meilleurs projets
7. Cliquer "Créer le projet"
